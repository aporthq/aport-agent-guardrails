# Second-pass review of the 1.0.34 changes

Date: 2026-09-24
Scope: everything on `feat/passport-reuse-and-docs` (passport reuse, hosted-mode fixes for Codex and Claude Code, the issue #107 drift work, the default-branch protection wiring). Eight review angles ran over the diff after the first fix pass: line-by-line, guards and invariants, removed behaviour, cross-file tracing, reuse, simplification, efficiency and altitude. This record ties each finding that survived verification to its fix and to the test that covers it.

## Outcome

Twenty-one findings fixed. No finding was deferred. One deeper issue stays out of scope on purpose: the local bash evaluator denies a shell call with no timeout evidence while the policy JSON allows it. That is tracked as a follow-up in the agent-passport policy README and in Gallivant's decisions log, because the fix belongs in the policy contract, not in a per-harness default table.

## What the review did not change

- The local bash evaluator's timeout-evidence rule (see above).
- Gemini CLI and Goose keep a strict tool list with no payload fallback; their tool sets are small and documented, and the Codex fallback exists because Codex ships new tool names between releases.
